# Driver app

Independent Flutter Android application for HireD drivers. It calls the shared backend API.

- `lib/`: Dart application source.
- `test/`: Flutter and Dart tests.

This directory is a skeleton, not a runnable Flutter application. During initialization, select and pin the compatible Flutter/Dart and Android toolchain, generate the platform files, and add this project's `pubspec.yaml` and `pubspec.lock`. Document actual dependency, emulator/device, test and build commands here once they exist.

Use Flutter/Dart tooling from this directory. The mobile application is not a pnpm package or a Docker runtime service.

References: [UI specification](../docs/ui-ux-specification.md), [mobile designs](../docs/design/mobile/README.md), [API contract](../docs/api/openapi.yaml) and [naming conventions](../docs/naming-conventions.md).
